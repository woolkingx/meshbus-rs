Owner Proofs

ProofRequired assertion
Stream boundaryOne logical stream open maps to Mesh Protocol StreamOpen, followed by ordered opaque StreamData and explicit close/half-close frames. Multiple return packets drained from one socket-read batch must remain visible to later recv() calls.
Datagram boundaryOne logical send_to maps to one Mesh frame datagram in/out with endpoint metadata.
Mesh peer contractOwn config required keys are enforced and no unknown config keys are accepted.
Fail-safe policyUnsupported payload/secret-size conditions are rejected and reported by tests in tests/egress.rs.
