Owned Data

TypeContract
CounterObserverOwns an Arc<Mutex<HashMap<String, u64>>> snapshot store for selected exit counters.
snapshot()Returns a cloned map of exit_id => dispatch count.

Observer plugin owns only counting state, no scheduling, routing, or network transport state.

Schema / Fixture Source

schema.json declares no runtime fields; construction is via CounterObserver::new().

  • tests/schema.rs: closed-schema proof by text check.
  • tests/counter.rs: count increments on FlowOpened and snapshots.
