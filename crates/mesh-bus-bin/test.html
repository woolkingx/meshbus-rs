Schema / Fixture Source

E2E Projections

  • CLI check/run path parity is verified by tests/e2e.rs and tests/boot.rs.
  • In-process e2e compositions prove binary contract by driving run from YAML fixtures in tests/e2e_composition.rs.
  • Product topology fixtures prove local SOCKS5 over MeshPeer re-entry into remote TCP and SOCKS5 stream egress without assigning protocol ownership to Mesh Protocol.
