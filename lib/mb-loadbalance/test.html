Owned Data

DataContract
CandidateWeighted candidate input row.
Wrr / SwrrMutable picker cursors for weighted distribution.
ConsistentHashStable key-to-candidate projection over weighted rows.
StickyTablePer-key sticky candidate state with TTL and repick rules.
SourceLeaseRotatePer-source lease state with idle expiry, max-age policy, generation, and cooldown.
SourceLeaseActivityExternal source lifecycle evidence: absent means unknown/no evidence, active means active_flows>0, true idle means active_flows=0 plus idle_since_ms. The half-idle shape active_flows=0 without idle_since_ms is invalid schema data and falls back to unknown in code.

This module owns local algorithm state only. It owns no health evidence, dispatch runtime, scheduler plugin wiring, or network I/O.

Owner Proofs

ProofRequired assertion
Weighted distributionHigher-weight candidates receive more picks over repeated samples.
Hash stabilityThe same key and candidate set maps to the same candidate across rebuilt hashers.
Sticky TTLA key keeps its selected candidate until expiry.
Source lease rotationA source keeps its lease until external source activity reports active_flows=0 plus idle expiry, or candidate disappearance, when max-age policy is off; explicit soft/hard max-age policies are separate rotation modes, and hard switches when an alternative exists.
Source activity shapeSourceLeaseActivity accepts only active-source or true-idle data. Unknown activity uses lease last_seen fallback; invalid legacy half-idle input cannot block idle expiry forever.
Candidate disappearanceSticky state repicks when the previous candidate is no longer available.
Empty inputPickers return None when no usable candidate exists.
