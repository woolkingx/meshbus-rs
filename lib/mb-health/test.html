mb-health - Owner Proof Contract

Classification: stateful data owner. This module owns bounded health evidence windows and per-exit failure/recovery state.

Owned Data

DataContract
HealthWindowBounded RTT, outcome, EWMA jitter, and payload-byte windows.
HealthPolicyFailure threshold, recovery window, and probe delay constants.
ExitHealthTablePer-exit failure counters, last failure, last success, and probe gating.

The caller owns clock samples and exit identity strings. This module owns only the health-state mutation rules.

Owner Proofs

ProofRequired assertion
Bounded windowRTT and byte windows evict oldest samples at capacity.
EWMA and jitterMean RTT and jitter respond to samples while resisting single spikes.
GoodputByte samples over time produce byte-per-second estimates; insufficient samples return zero.
Success rateOutcome window returns the success fraction, defaulting to 1.0 when empty.
Exit healthFailures mark exits unhealthy, probe delay re-admits them, and success recovers them.

Integration Boundaries

ConsumerBoundary
mesh-bus-core dispatchConsumes ExitHealthTable as health evidence and owns dispatch decisions.
SchedulersConsume RTT, jitter, success, and goodput evidence without owning the health mutation rules.

Forbidden Tests

ForbiddenReason
Wall-clock, sleep, socket, or async runtime testsCallers pass now_ms; health state is deterministic data.
Scheduler ranking or dispatch selection testsThose are composition owners.
Network reachability assumptionsThis module records evidence; it does not create it.
