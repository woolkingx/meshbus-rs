Owned Data

DataContract
EndpointValidated in-memory endpoint with private host: String and port: u16.
ParseErrorTyped rejection data for malformed or illegal endpoint input.

The module owns no DNS lookup, resolver cache, socket, route selection, or network reachability.

Schema Source

schema.json declares the parser/type owner and points to shared endpoint wire format under /schemas/endpoint.schema.json. Runtime behavior lives in src/lib.rs.

Owner Proofs

ProofRequired assertion
Pure parserParsing and display use string operations and value construction only; no I/O.
No panic on untrusted inputInvalid inputs return ParseError variants.
Host legalityEmpty host and host length greater than 255 bytes are rejected.
Port legalityPort 0 and non-u16 port text are rejected as InvalidPort.
IPv6 surfaceBracketed IPv6 parse succeeds; display brackets hosts containing :.

Integration Boundaries

BoundaryContract
Caller to mb-endpointCaller supplies endpoint text or explicit host/port values.
mb-endpoint to consumerConsumer receives validated Endpoint and must not redo parser ownership in resolver or transport layers.
Dependencythiserror formats typed parser errors.

E2E Projections

  • Runtime config and protocol adapters must validate endpoint text before opening transport resources.
  • Resolver and network tests may consume Endpoint, but must not redefine parser rules.

Forbidden Tests

ForbiddenReason
