Owner Proofs

The runner must build or reuse the release binary, prefer a glibc-independent musl target for the lab, deploy pool nodes before the gateway, install each role to the binary path its systemd unit actually executes, preserve remote configs, aggregate per-host deploy/service JSON, and optionally run tests/live-run2-pool-validation.mjs.

Integration Boundaries

Single-host deployment remains owned by deploy/service. Runtime YAML remains owned by config/runtime. Product traffic proof remains owned by tests/live-run2-pool-validation.mjs.

Forbidden Tests

This wrapper must not rewrite route policy, generate MeshSec keys, mutate peer topology, or infer product correctness from systemd active state alone.
