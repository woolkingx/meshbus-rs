Owner Proofs

The runner must hash local inputs, backup existing remote artifacts, install via temporary paths, run remote config preflight, restart the service, verify systemctl is-active, and emit JSON evidence. Binary release may preserve remote config when config is remote-owned service data.

Integration Boundaries

Runtime YAML remains owned by mesh-bus-runtime. The systemd unit remains owned by deploy/systemd. This adapter composes those owners through the remote host boundary.

Forbidden Tests

No policy, route, peer, MeshSec, scheduler, or packet behavior belongs here. Those proofs stay in runtime, protocol, and product e2e gates.
